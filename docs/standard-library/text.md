# std/text Reference

UTF-8 string manipulation and conversion utilities.

- `is_empty(s: Text) -> Bool` — Checks if string is empty.
- `reverse(s: Text) -> Text` — Reverses character sequence.
- `upper(s: Text) -> Text` — Uppercase conversion.
- `lower(s: Text) -> Text` — Lowercase conversion.
- `trim(s: Text) -> Text` — Strips whitespace.
- `replace(s: Text, a: Text, b: Text) -> Text` — Replaces substrings.
- `split(s: Text, delim: Text) -> Text` — Splits string.
