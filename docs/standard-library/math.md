# std/math Reference

Mathematical utilities, power operations, clamps, and integer trigonometry.

- `abs(x: Int) -> Int` — Returns absolute value.
- `square(x: Int) -> Int` — Returns $x^2$.
- `max(a: Int, b: Int) -> Int` — Returns maximum.
- `min(a: Int, b: Int) -> Int` — Returns minimum.
- `pow(base: Int, exp: Int) -> Int` — Integer power calculation.
- `clamp(val: Int, min_val: Int, max_val: Int) -> Int` — Clamps value within bounds.
- `sin_deg(deg: Int) -> Int` — Returns scaled sine value.
- `cos_deg(deg: Int) -> Int` — Returns scaled cosine value.
- `hypot_int(a: Int, b: Int) -> Int` — Returns integer hypotenuse.
