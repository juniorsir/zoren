# std/ai Reference

Multidimensional Tensor computing and analytical autograd.

- `Tensor[T]` — Multidimensional tensor model.
- `create_tensor_2d(r: Int, c: Int) -> Int` — Allocates 2D tensor.
- `matmul_2d(a: Int, b: Int) -> Int` — Matrix multiplication.
- `backward_autograd(loss: Int) -> Int` — Reverse-mode gradient calculation.
