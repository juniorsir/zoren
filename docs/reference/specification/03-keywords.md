# Reserved Keywords

## SYNTAX
The 41 keywords (`flow`, `bind`, `flex`, `deliver`, `assess`, `case`, `repeat`, `while`, `bring`, `as`, `use`, `model`, `open`, `ability`, `grant`, `enum`, `divert`, `diverges`, `catch`, `async`, `await`, `ensure`, `comptime`, `compute_kernel`, `accel`, `actor`, `chamber`, `extern`, `ABI`, `null`, `true`, `false`, `if`, `else`, `for`, `in`, `break`, `continue`, `escape`, `skip`) MUST NOT be redefined.
