# 🌐 The Zoren Developer Community

Welcome to the Zoren Language Community! We are a global network of systems programmers, kernel developers, security researchers, and high-performance computing engineers pioneering a faster, memory-safe future.

---

## 🏛️ Community Hubs

* **GitHub Discussions**: [**github.com/juniorsir/zoren/discussions**](https://github.com/juniorsir/zoren/discussions)  
  The primary forum for asking questions, sharing benchmarks, proposing RFCs, and showcasing community modules.
* **Module Showcase**: [**Discussions / Module Showcase**](https://github.com/juniorsir/zoren/discussions)  
  Share libraries, frameworks, utilities, and bindings you have written for Zoren.
* **Issue Tracker**: [**github.com/juniorsir/zoren/issues**](https://github.com/juniorsir/zoren/issues)  
  Report bugs, crashes, documentation errors, or feature requests.
* **Sponsorship Hub**: [**github.com/sponsors/juniorsir**](https://github.com/sponsors/juniorsir)

---

## 🤝 Community Guidelines & Values

1. **Craftsmanship & Rigor**: We value deep technical precision, measurable performance benchmarks, and verified memory safety.
2. **Encouraging New Builders**: Whether you are a seasoned systems architect or learning low-level programming for the first time, all constructive questions are welcomed.
3. **Respect Intellectual Property**: Respect the intellectual property of authors. Never republish proprietary compiler binaries under alternate branding or upload unauthorized copies of private codebases.
4. **Collaboration Over Ego**: Share knowledge generously, review module code constructively, and help fellow developers succeed.

---

## 🚀 Ways to Get Involved

1. **Build a Module**: Write a high-performance library (networking, serialization, data structures, graphics, cryptography) using our [Module Development Guide](MODULE_DEVELOPMENT.md).
2. **Benchmark Your Apps**: Port CPU-intensive routines from C, Rust, or Python into Zoren and share your speedup numbers.
3. **Contribute to Tooling**: Improve editor integrations, documentation examples, and language guides.
4. **Sponsor**: Become a GitHub Sponsor to support full-time development and infrastructure.
